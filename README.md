# Jogo da Memória

Projeto desenvolvido como **desafio de projeto** na **Digital Innovation One (DIO.me)**.

## 💡 Sobre o projeto
O **Jogo da Memória** é um jogo simples em que o jogador precisa encontrar pares de cartas iguais.
É um ótimo exercício para treinar lógica de programação, manipulação do DOM (se for web) e conceitos de desenvolvimento de front-end.

## 🎯 Funcionalidades
- Início do jogo com cartas embaralhadas.  
- Clique nas cartas para revelar e tentar formar pares.  

## 🛠 Tecnologias utilizadas
- HTML  
- CSS  
- JavaScript
